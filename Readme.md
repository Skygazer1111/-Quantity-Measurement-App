# Quantity Measurement App

A Java project for modeling quantities across different unit types and performing comparisons and arithmetic.

## Features
- Length, volume, and weight units
- Quantity comparison and equality checks
- Quantity arithmetic operations
- Unit conversion support via shared interfaces

## Project Structure
- `src/`: application and domain classes
- `test/`: unit tests

## How to Run Tests
Run your test suite from your IDE or with your build tooling (if configured). For example, use your IDE's test runner to execute tests under the `test/` folder.

## Notes
This project uses plain Java classes under `src/` and JUnit-style tests under `test/`.
